# Уравнение Рэлея
Уравнение Рэлея во многом похоже на уравнение Ван-дер-Поля. Рассматривается задача вида:

$$
\frac{d^2x}{dt^2}-\mu (1-(\frac{dx}{dt})^2)\frac{dx}{dt}+x=0
$$
Решить задачу, записав уравнение Рэлея в виде системы ОДУ. Начальные условия: x(0)=0, $\dot{x}$(0)=0.001, $\mu$=1000, $T_k$=1000
